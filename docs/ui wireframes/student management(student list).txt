# MAIN UI COMPONENTS

1. Header
a. App logo
b. Page title
c. Notification icon
d. Admin profile
e. Theme toggle
2. Sidebar
a. Same navigation as your Admin Dashboard.
3. Search
 Search by:
a. Student name
b. Student ID
c. Email
d. Phone number
4. Filters
a. Course       [▼ All Courses]
b. Semester     [▼ All Semesters]
c. Status       [▼ Active / Inactive]
d. Attendance   [▼ All / Below 75%]

# STUDENT TABLE

Each student gets one row.

1. Field              |          Purpose
2. Student ID         |  Unique identification
3. Name               |   Student name
4. Course             |    BCA/BSc/etc.
5. Semester           |     Current semester
6. Email              |     Contact
7. Attendance         |      Percentage
8. Status             |       Active/Inactive
9. Actions            |        View/Edit/Delete

# IMPORTANT UX RULES

Keep these consistent throughout your project:

1. Don't permanently show a huge table; use pagination.
2. Ask for confirmation before deleting.
3. Show success/error feedback after actions.
4. Keep Add Student clearly visible.
5. Keep search and filters near the top.
6. Don't overcrowd the sidebar.
7. Use the same button, table, and card style throughout the application.
