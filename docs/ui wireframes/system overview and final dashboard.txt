# PURPOSE

The dashboard gives a single-screen overview of the entire Student Management System.

It should answer:

"What's happening in my institution right now?"

The Admin should immediately see:

1. Students
2. Teachers
3. Courses
4. Attendance
5. Marks
6. Fees
7. Library
8. Notifications
9. At-risk students
10. AI insights
11. Recent activity
