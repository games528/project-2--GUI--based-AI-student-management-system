THIS SCREEN IS USED BY THE ADMIN TO CREATE A NEW COURSE/SUBJECT IN THE SYSTEM.

# PURPOSE

admin can define:
1. course identify
2. department
3. semester
4. credits
5. description
6. teacher assignment 
7. student capacity
8. course status

# VALIDATION

check:
1. course code isn't empty
2. course code is unique
3. course name is required
4. department is selected
5. semester is selected
6. credits are valid 
7. Maximum students count is valid
8. teacher exists if assignment is required
