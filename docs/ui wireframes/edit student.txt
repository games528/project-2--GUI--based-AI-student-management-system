THIS SCREEN IS ALMOST IDENTICAL TO ADD STUDENT, BUT INSTEAD OF CREATING A NEW RECORD, IT LOADS AN EXISTING STUDENT'S INFORMATION AND ALLOWS THE ADMIN TO MODIFY IT.

# PURPOSE

Admin can:

1. Update student information
2. Change course/semester
3. Update contact details
4. Update guardian information
5. Change profile photo
6. Save changes
7. Reset changes
8. Cancel editing

# IMPORTANT DIFFERENCE FROM ADD STUDENT

The Student ID should be locked.
Student ID: STU2026001 🔒
The admin shouldn't accidentally change the unique identifier.

# EDITABLE FIELDS 

Personal:

1. Name
2. Date of birth
3. Gender
4. Photo

Contact:

1. Email
2. Phone

Academic:

1. Course
2. Department
3. Semester
4. Section

Guardian:

1. Guardian name
2. Relationship
3. Guardian phone
4. Guardian email

Address:

1. Full address

| Do you want to leave without saving?        |
|                                             |
| [ Stay ]   [ Save Changes ]   [ Leave ]     |
+---------------------------------------------+
This is a good professional UX feature.

# VALIDATION

Check:
1. Required fields aren't empty.
2. Email is valid.
3. Phone number is valid.
4. Course exists.
5. Semester is valid.
6. No invalid characters in appropriate fields.
7. Student ID remains unchanged.
