THIS SCREEN IS USED TO ENTER AND MANAGE STUDENTS' MARKS FOR A SELECTED COURSE/SUBJECT AND EXAM.

# PURPOSE

The teacher/admin should be able to:

1. Select course
2. Select semester/section
3. Select exam type
4. Enter marks
5. Automatically calculate total/percentage
6. Automatically assign grades
7. Search students
8. Save marks
9. Edit existing marks
10. Detect invalid marks

# MAXIMUM MARKS

Maximum Marks

[ 50 ]

This is important because the system needs to validate the entered marks.
For example:

Maximum = 50
Entering 57 should immediately produce:

❌ Marks cannot be greater than 50.

# MARKS TABLE

# AUTOMATIC GRADE CALCULATION

Don't make the teacher manually enter grades.

Example grading system:
90–100 → A+
80–89  → A
70–79  → B
60–69  → C
50–59  → D
<50    → F

You can later make the grading scale configurable from Settings.

# AUTOMATIC PERCENTAGE

If:
Marks = 45
Maximum = 50

Then:
Percentage = 45 / 50 × 100
           = 90%

The UI automatically displays:
45 / 50
90%
A+

# VALIDATION

Check:

1. Course selected
2. Semester selected
3. Section selected
4. Exam type selected
5. Maximum marks valid
6. Marks cannot be negative
7. Marks cannot exceed maximum
8. Student cannot have duplicate marks for same exam
9. Empty marks should be handled explicitly

# ERROR MESSAGES

❌ Marks cannot be negative.

❌ Marks cannot exceed maximum marks.

❌ Please select an exam type.

❌ Please enter marks for all required students.

❌ Marks already exist for this exam.
