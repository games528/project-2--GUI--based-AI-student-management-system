THIS IS WHERE THE ADMINISTRATOR CONTROLS THE APPLICATION'S GENERAL SETTINGS, ACADEMIC RULES, LIBRARY RULES, NOTIFICATIONS, AI SETTINGS, AND SECURITY PREFERENCES.

# PURPOSE

Admin can configure:

1. College/system information
2. Academic settings
3. Attendance rules
4. Library rules
5. Fee settings
6. Notification preferences
7. AI settings
8. Security settings
9. Backup/data settings
