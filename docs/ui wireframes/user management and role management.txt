THIS SCREEN IS FOR THE SUPER ADMIN/ADMINISTRATOR TO MANAGE WHO CAN ACCESS THE SYSTEM AND WHAT THEY ARE ALLOWED TO DO.

THIS IS IMPORTANT BECAUSE YOUR PROJECT ALREADY HAS ADMIN, TEACHER, AND STUDENT ROLES.

# PURPOSE

Admin can:

1. View all system users
2. Add users
3. Edit users
4. Activate/deactivate accounts
5. Assign roles
6. Search users
7. Filter users
8. Reset passwords
9. Manage permissions
10. View account status
