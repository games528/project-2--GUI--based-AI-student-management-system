THIS IS THE MAIN DATA VISUALIZATION AND PERFORMANCE ANALYSIS SCREEN OF YOUR AI STUDENT MANAGEMENT SYSTEM.

UNLIKE THE REPORTS SCREEN, WHICH GENERATES SPECIFIC REPORTS, ANALYTICS GIVES A LIVE VISUAL OVERVIEW OF WHAT'S HAPPENING ACROSS THE COLLEGE.

# PURPOSE

Admin should be able to see:

1. Student performance
2. Attendance trends
3. Marks trends
4. Fee collection
5. Course performance
6. Library usage
7. At-risk students
8. AI-generated insights
