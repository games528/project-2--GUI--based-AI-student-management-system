# IMPORTANT UX RULE

Don't put everything into one giant page.
Use sections/tabs:

[Overview] [Attendance] [Marks] [Fees] [Courses] [Activity]

The Overview tab is the screen above.
This keeps the application clean and makes it much easier to implement.
