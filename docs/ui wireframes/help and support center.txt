# FAQ SECTION

FREQUENTLY ASKED QUESTIONS

▼ How do I add a new student?
  Go to Students → Add Student and fill in
  the required information.

▼ How do I issue a library book?
  Go to Library → Issue Book.

▼ How do I generate a report?
  Go to Reports → Select Report Type → Generate.

▼ How does the AI Assistant work?
  The AI analyzes available system data and
  provides summaries and answers.

Use expandable questions instead of showing huge amounts of text at once.
