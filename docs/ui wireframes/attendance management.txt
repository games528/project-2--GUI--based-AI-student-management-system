THIS IS THE MAIN ATTENDANCE SCREEN. THE ADMIN/TEACHER CAN SELECT A COURSE, DATE, AND STUDENT LIST, THEN MARK ATTENDANCE.

# PURPOSE

The screen should allow:

1. Select course/subject
2. Select semester/section
3. Select date
4. View enrolled students
5. Mark Present/Absent
6. Mark everyone present/absent
7. Search students
8. Save attendance
9. View attendance percentage
10. Edit previously recorded attendance

# STUDENT ATTENDANCE TABLE

Each student gets one row.
ID      |    Student     |      Present     |        Absent     |    Status
101     |    Rahul Kumar |         ●        |            ○      |    🟢 Present
102     |    Aman Singh  |         ○        |            ●      |    🔴 Absent
103     |    Riya Sharma |         ●        |            ○      |    🟢 Present

Use radio buttons so the user can't accidentally select both Present and Absent.

# DUPLICATE ATTENDANCE PROTECTION

If attendance for that course/date has already been recorded:
+---------------------------------------------+
|          Attendance Already Exists          |
|                                             |
| Attendance for Python on 09/08/2026        |
| has already been recorded.                 |
|                                             |
| [ View Existing ] [ Edit Attendance ]       |
| [ Cancel ]                                  |
+---------------------------------------------+
This prevents accidental duplicate records.

# VALIDATION

Before saving:

1. Course must be selected.
2. Semester must be selected.
3. Section must be selected.
4. Date must be valid.
5. Every student must have a status.
6. Duplicate attendance should be detected.
