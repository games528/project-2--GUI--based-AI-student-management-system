THIS IS THE MAIN SCREEN FOR MANAGING ALL COURSES/SUBJECTS IN YOUR SYSTEM.

# PURPOSE

Admin can:

1. View all courses
2. Search courses
3. Filter by department/semester
4. Add a course
5. Edit a course
6. View course details
7. Assign teachers
8. See enrolled students
9. Activate/deactivate courses
10. Export course data
