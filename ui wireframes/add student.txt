# FORM SECTIONS

A. Student Photo

1. Upload image
2. Preview image
3. Remove image
[ Upload Photo ]

        ↓

[   Photo   ]  [Remove]

B. Personal Information

Fields:
1. Student ID — automatically generated
2. Full Name
3. Date of Birth
4. Gender

Student ID should not be manually entered to prevent duplicate IDs.

Example:
Student ID: STU2026001

C. Contact Information

1. Email
2. Phone number
3. Optional alternate phone

D. Academic Information

1. Course
2. Department
3. Semester
4. Admission year
5. Section
Example:
Course       [ BSc AI & Data Science ▼ ]
Department   [ Computer Science ▼ ]
Semester     [ 1 ▼ ]
Section      [ A ▼ ]

E. Guardian Information

1. Guardian name
2. Relationship
3. Guardian phone
4. Guardian email (optional)

F. Address

Use a multi-line text box.

# BUTTONS 

✓ Save Student
Flow:
Fill Form
   ↓
Validate
   ↓
Save to Database
   ↓
Success Message
   ↓
Student Management

Reset:
Clears all entered information.

Cancel:
Returns to Student Management without saving.

# VALIDATION 

Before saving:
1. Name cannot be empty.
2. Date of birth must be valid.
3. Email must have valid format.
4. Phone number must be valid.
5. Course must be selected.
6. Semester must be selected.
7. Guardian information must be valid.
8.Duplicate student records should be prevented.

# VALIDATION MESSAGES 

❌ Full name is required.

❌ Invalid email address.

❌ Invalid phone number.

❌ Please select a course.

❌ Please select a semester.

# UX IMPROVEMENTS 

For a polished application:
1. Auto-generate Student ID.
2. Use dropdowns instead of free-text fields where appropriate.
3. Show real-time validation.
4. Highlight invalid fields.
5. Display image preview.
6. Disable Save until required fields are valid.
7. Warn before leaving with unsaved changes.
8. Use tab/Enter navigation between fields.
