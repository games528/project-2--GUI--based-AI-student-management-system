THIS SCREEN MANAGES THE LOGGED-IN USER'S PROFILE, ACCOUNT INFORMATION, PASSWORD, SECURITY, AND SESSION ACTIVITY.

# PURPOSE

Admin can:

1. View profile
2. Edit personal information
3. Change password
4. Manage security
5. View login/session activity
6. Log out other sessions

# PASSWORD VALIDATION

Check:

Current password is correct
New password meets your minimum requirements
New password and confirmation match
New password differs from the old password

Errors:

❌ Current password is incorrect.

❌ Passwords do not match.

❌ Password doesn't meet the required criteria.
