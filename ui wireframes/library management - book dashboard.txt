THIS IS THE MAIN SCREEN FOR MANAGING BOOKS, AVAILABILITY, ISSUED BOOKS, RETURNS, AND OVERDUE BOOKS.

# PURPOSE

Admin/library staff can:

1. View all books
2. Search books
3. Filter books
4. Add books
5. Edit book details
6. Issue books
7. Return books
8. Track overdue books
9. View available copies
10. Generate library reports

# ADD BOOK

[ + Add Book ]

This opens the Add Book screen.

Information will include:

1. Book ID
2. ISBN
3. Title
4. Author
5. Publisher
6. Category
7. Publication year
8. Number of copies
9. Shelf/location

# ISSUE BOOK

[ Issue Book ]

Opens:
+---------------------------------------------+
|              Issue Book                     |
|                                             |

| Book          [▼ Select Book]               |

| Due Date      [ 23/08/2026 📅 ]             |
|                                             |
| [ Cancel ]           [ ✓ Issue Book ]       |
