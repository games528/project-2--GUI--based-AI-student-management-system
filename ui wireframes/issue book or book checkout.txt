THIS SCREEN HANDLES LENDING A LIBRARY BOOK TO A STUDENT OR TEACHER.

# PURPOSE

The librarian/admin can:

1. Select borrower
2. Search/select a book
3. Check availability
4. Set issue and due dates
5. Record the issue
6. Generate a transaction/issue ID
7. Prevent issuing unavailable books

# AVAILABILITY CHECK ⭐

This is critical.

If:
Total Copies: 10
Available: 7

show:
🟢 Available

If:
Available: 0

show:
🔴 No copies available

and disable:
[ Issue Book ]

# ISSUE DATE

Default to today's date:
Issue Date
[ 09/08/2026 📅 ]

The admin can change it if necessary.

# DUE DATE

Due Date
[ 23/08/2026 📅 ]
You can automatically calculate it.

For example:
Issue Date + 14 days = Due Date

Later, make the borrowing period configurable in Settings.

# VALIDATION

Check:

1. Borrower selected
2. Book selected
3. Book is available
4. Due date is valid
5. Borrower hasn't exceeded borrowing limit
6. Book isn't already issued to the same borrower
7. All required information exists

# BORROWING LIMIT

For example, you can configure:
Maximum active books: 3

If Rahul already has 3 books:
⚠ Borrowing Limit Reached

This student already has 3 active books.

Return an existing book before issuing another.

This is a good database/business-rule feature.
