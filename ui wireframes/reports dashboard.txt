THIS IS THE CENTRAL PLACE WHERE THE ADMIN CAN GENERATE AND VIEW REPORTS FROM STUDENTS, ATTENDANCE, MARKS, FEES, COURSES, AND LIBRARY DATA.

# PURPOSE

The admin should be able to:

1. Select a report type
2. Apply filters
3. Preview results
4. Generate reports
5. Export as PDF/Excel/CSV
6. Print reports
7. View summary statistics

# FILTERS

Filters change depending on the report.

Common filters:
Department   [▼ All]
Semester     [▼ All]
Section      [▼ All]
Course       [▼ All]
Date Range   [ Start 📅 ] — [ End 📅 ]

Example:
Semester: 1
Course: Python
Date: 01/08/2026 → 31/08/2026
