# BUTTON ACTIONS

1. send OTP
a. verify that the email or phone number exists
b. generate a 6 digit OTP
c. send the OTP 

2. Reset password
a. verify the OTP
b. check that the passwords match
c. update the password in the database
d. redirect to the login screen 

3. back to login
a. return to the login page


# VALIDATION

1. email cannot be empty
2. email must exist in the database
3. username must exist
4. phone number must match the registered account
5. OTP must be correct
6. password must contain:
a. at least 8 characters
b. 1 uppercase letter
c. 1 lowercase letter
d. 1 digit
e. 1 special character 
7. confirm password must match

# success messages

1. OTP sent successfully
2. OTP verified
3. password changed successfully

# ERROR MESSAGES 

1. email not found
2. username does not exist
3. invalid OTP
4. OTP expired
5. passwords do not match
6. weak password
