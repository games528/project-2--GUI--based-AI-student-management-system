THIS SCREEN MANAGES ALL SYSTEM NOTIFICATIONS FOR STUDENTS, TEACHERS, AND ADMINISTRATORS.

# PURPOSE

Users should be able to:

1. View notifications
2. Mark notifications as read/unread
3. Filter notifications
4. Delete/dismiss notifications
5. Open the related screen
6. See important alerts
7. Manage notification preferences

# NOTIFICATION CATEGORIES

Use categories:
🔴 Important
🟡 Academic
🔵 Library
🟣 Fees
🟢 System

Examples:

Academic

Low attendance
Marks published
Exam result available
Assignment deadline

Fees

Payment due
Payment overdue
Payment received

Library

Book issued
Book due soon
Book overdue
Book returned

System

New course created
Report generated
Account/security notification

# NOTIFICATION CARD

Each notification should contain:
🔴  Fee Payment Overdue

Rahul Kumar has ₹10,000 pending.

2 hours ago

[ View Details ]

Unread notifications should be visually distinguishable.

For example:
●  Fee Payment Overdue

Read:
   Fee Payment Overdue

Don't rely only on color to distinguish them.

# FILTERS

[ All ] [ Unread ] [ Academic ] [ Fees ] [ Library ] [ System ]

Example:

Click Unread:
Showing: 3 unread notifications

# MARK AS READ

Each notification can have:
⋮
├── Mark as read
├── Open
└── Delete

And at the top:
[ ✓ Mark All as Read ]

# NOTIFICATION CLICK BEHAVIOR

Notifications should take the user directly to the relevant page.

Example:
Fee overdue
     ↓
Click
     ↓
Fee Details
     ↓
Student's fee record

Another:
Low attendance
     ↓
Click
     ↓
Attendance Management
     ↓
Filtered students

This makes the system feel much more connected.
