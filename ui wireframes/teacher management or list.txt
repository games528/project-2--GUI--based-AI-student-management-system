THIS IS THE MAIN SCREEN FOR MANAGING ALL TEACHERS IN THE SYSTEM.

# PURPOSE

Admin can:

1. View all teachers
2. Search teachers
3. Filter teachers
4. Add teacher
5. View teacher profile
6. Edit teacher
7. Delete/deactivate teacher
8. Assign courses/subjects
9. Export teacher data

# DELETE / DEACTIVATE

Instead of immediately deleting a teacher, prefer:

+------------------------------------------+
|       Deactivate Teacher?                |
|                                          |
| Amit Kumar will no longer be active.     |
|                                          |
| [ Cancel ]          [ Deactivate ]       |
+------------------------------------------+

This is safer because their previous attendance/marks records may still be needed.
