THIS SCREEN ALLOWS THE ADMIN TO CREATE A COMPLETE TEACHER PROFILE AND ASSIGN THEIR DEPARTMENT AND SUBJECTS.

# PURPOSE

Admin can add:

1. Teacher personal details
2. Contact information
3. Professional information
4. Department
5. Subjects
6. Profile photo
7. Joining information

1. Name required
