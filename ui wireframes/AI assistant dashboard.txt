THIS IS THE AI-POWERED CENTRAL SCREEN OF YOUR PROJECT. UNLIKE THE NORMAL DASHBOARD, THIS SCREEN LETS ADMINISTRATORS/TEACHERS ASK QUESTIONS ABOUT THE STUDENT-MANAGEMENT DATA AND RECEIVE USEFUL SUMMARIES.

# PURPOSE

The AI Assistant should be able to:

1. Answer questions about student data
2. Summarize attendance
3. Analyze marks
4. Identify academic patterns for staff review
5. Summarize fee data
6. Analyze course performance
7. Explain generated reports
8. Generate suggestions based on existing data
9. Search system information using natural language

# CHAT AREA

The center should look like a normal AI chat interface.

User message
👤 You

Which course has the lowest average marks?

AI response
🤖 AI Assistant

Based on the current marks data:

Physics has the lowest average score at 69%.

Would you like me to show the students
who scored below the class average?

📅 Analyze Attendance

💰 Analyze Fees
