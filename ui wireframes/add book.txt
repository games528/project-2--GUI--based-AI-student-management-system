THIS SCREEN IS USED TO ADD A NEW BOOK AND ITS INVENTORY INFORMATION TO THE LIBRARY.

# PURPOSE

Admin/library staff can enter:

1. Book details
2. ISBN
3. Author/publisher
4. Category
5. Publication information
6. Number of copies
7. Shelf/location
8. Book status

# VALIDATION

Check:

1. Title required
2. Author required
3. ISBN format valid
4. ISBN isn't already registered
5. Publication year valid
6. Category selected
7. Number of copies > 0
8. Shelf/location entered if required

# ERROR MESSAGES

❌ Book title is required.

❌ Author name is required.

❌ Invalid ISBN.

❌ This ISBN already exists.

❌ Number of copies must be greater than 0.

❌ Please select a category.
