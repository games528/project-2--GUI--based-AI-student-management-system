THIS SCREEN ALLOWS THE ADMIN TO MODIFY AN EXISTING TEACHER'S INFORMATION WITHOUT CREATING A NEW TEACHER RECORD.

# PURPOSE

Admin can:

1. Update teacher details
2. Change contact information
3. Update qualification/specialization
4. Change department
5. Add/remove assigned subjects
6. Change profile photo
7. Save or discard changes
